# Project Agent Guidelines: Always Plan Mode

All work on this codebase must strictly adhere to **Always Plan Mode**:

1. **Step 1 - Research & Plan**:
   - For every task, thoroughly research the codebase and write/update `implementation_plan.md`.
   - Never modify production source code or execute destructive operations before plan review.
2. **Step 2 - User Approval**:
   - Stop and wait for the user's approval on the implementation plan.
3. **Step 3 - Execution & Verification**:
   - Execute the approved plan.
   - Run tests and document the outcome in `walkthrough.md`.
